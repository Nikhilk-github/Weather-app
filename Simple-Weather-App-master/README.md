# "Simple Weather Application using HTML, CSS &amp; JavaScript"

## Overview of Weather App

**How It Works**
User enters a city name (e.g., “Delhi”)
App sends a request to the weather API
API returns data like:
Temperature 🌡️
Weather condition (Cloudy, Sunny, Rainy) ☁️
Humidity 💧
Wind speed 🌬️
App displays this data on the screen
